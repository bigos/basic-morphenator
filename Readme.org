* Readme
I am trying to copy elements of Cuis Smalltalk Morphic GUI framework.

https://github.com/Cuis-Smalltalk/Cuis-Smalltalk-UI

At the moment this project is at very early stages.

We have a substantial Cuis-style Morphic foundation in CLOS—complete with morph /
placed-morph / boxed-morph / world-morph / hand-morph, proportional & fixed
layout-spec handling, mouse-over enter/leave tracking, text selection/scrolling/
editing, Alt shortcuts, GTK4/Cairo integration, and a FiveAM test suite.

** dependencies
#+begin_example
sudo apt install libgtk-4-dev libgirepository-2.0-dev libgtk-4-doc
#+end_example

** running tests
#+begin_src common-lisp
  (asdf:load-system "basic-morphenator" :force t)

  ;; example program
  (basic-morphenator:main)

  ;; tests
  (asdf:test-system "basic-morphenator")
#+end_src
